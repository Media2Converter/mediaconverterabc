# Media Converter 

日本語のビデオ・オーディオコンバータアプリを作ってください。

デザイン　背景は黒､文字は全て白､ボタンの背景は赤く表示してください。

警告表示方法　全てiOSの警告を表示(詳細設定でどこか一つでもおかしかったりiPhoneで再生できなさそうな場合に表示してください。)

形式や詳細設定の選択候補メニュー表示方法　iOSのコンテクストメニューピッカーを起動(ビデオ・オーディオコーデックはiPhoneで再生エラーが出そうな項目は全て赤紫色の文字で表示してください。

アプリの流れは以下のようにしてください。

1アプリを開いたら「ファイルを選択」ボタンを表示。推したらメニューピッカーに、

写真ライブラリから選択

ビデオを録画

オーディオを録音

ファイルから選択

という項目を表示し､どれかを推したら写真ライブラリの選択ピッカーウィンドウ(ビデオファイルだけ表示)か､カメラウィンドウ(ビデオ撮影のみ)か、オーディオ録音ウィンドウか、ファイル選択ピッカーウィンドウ(ビデオ形式とオーディオ形式のファイルだけ表示)を起動。

 2アップロード後の流れ

ファイルをアップロードしたら「ファイルを追加」ボタンの下に形式と言うボタンを表示し､推したらメニューピッカーに以下の選択候補を表示してください。

動画形式(見出し表示)

MP4 M4V MOV 3G2 3GP AVI

音声形式(これも見出し表示)

OPUS EAC3 AC3 AAC MP3 WAV OGG AIFF RAW AMR_NB AMR_WB 

選んだらいつでも変更できるように選んだ形式を表示したボタンを表示してください。

3詳細設定

形式を選んだらその横に詳細設定ボタンを表示し､推したらiOSのポップアップウィンドウを起動してください。
